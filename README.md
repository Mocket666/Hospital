# Hospital

Ejercicio de programacion orientada a objetos en Java: equipos medicos, doctores, salas, pacientes y citas.

## Ejecucion

Requiere JDK 17 o posterior. Abre esta carpeta como proyecto en NetBeans y ejecuta el proyecto. La clase principal es `main.Main4`.

## Estructura

- `src/core`: clases del modelo y operaciones del hospital.
- `src/main/Main4.java`: ejemplo de uso y resultados esperados.
- `nbproject` y `build.xml`: configuracion del proyecto NetBeans/Ant.

Los archivos compilados y la configuracion privada de NetBeans se excluyen del repositorio.
